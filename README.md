# ЛР 4. Джойстик (АЦП)

## Мета
Зчитувати положення аналогового джойстика за допомогою АЦП мікроконтролера STM32F411VET6 і виводити нахил джойстика в PuTTY через порт USB USER (віртуальний COM-порт).

## Обладнання та ПЗ
- Плата STM32F411E-DISCO
- Аналоговий двоосьовий джойстик із кнопкою (виводи VRx, VRy, SW)
- Два кабелі micro-USB (ST-LINK і USB USER)
- STM32CubeMX, STM32CubeIDE, PuTTY

## Теоретичні відомості
Кожна вісь аналогового джойстика це потенціометр, що дає на виході напругу від 0 до 3,3 В залежно від нахилу. **АЦП** (аналого-цифровий перетворювач) переводить її в число: при розрядності 12 біт це діапазон 0..4095, нейтральному положенню відповідає значення близько 2048.

Для двох осей використовується один АЦП (ADC1) у **режимі сканування**: канали IN1 (PA1) і IN2 (PA2) перетворюються послідовно за один запуск.

## Підключення
| Джойстик | Плата |
|----------|-------|
| VCC | 3V (**не 5 В**: вхід АЦП витримує максимум 3,3 В) |
| GND | GND |
| VRx | PA1 (ADC1_IN1) |
| VRy | PA2 (ADC1_IN2) |
| SW | PA3 (вхід із підтяжкою вгору) |

## Параметри
| Параметр | Значення |
|----------|----------|
| Розрядність АЦП | 12 біт (0..4095) |
| Режим | Scan, 2 канали, програмний запуск |
| Час вибірки | 84 такти |
| Тактування АЦП | PCLK2 / 4 |
| Мертва зона | 25 % |
| Період виводу | 100 мс |
| PuTTY | Serial, 115200, Flow control: None |

## Алгоритм роботи
1. **Калібрування центру** при старті: усереднення 32 вимірювань у спокої (джойстик не торкатися).
2. Кожні 100 мс зчитуються значення X і Y.
3. Відхилення від центру переводиться у відсотки (-100..+100).
4. Якщо відхилення виходить за мертву зону (25 %), визначається напрям: LEFT, RIGHT, UP, DOWN або діагональ.
5. Також читається кнопка SW (натиснута = рівень 0).
6. Результат відправляється в PuTTY через USB CDC і оновлюється в одному рядку.

```c
void read_joystick(uint16_t *x, uint16_t *y)
{
    HAL_ADC_Start(&hadc1);
    HAL_ADC_PollForConversion(&hadc1, 10);
    *x = (uint16_t)HAL_ADC_GetValue(&hadc1);   // канал 1 (PA1)
    HAL_ADC_PollForConversion(&hadc1, 10);
    *y = (uint16_t)HAL_ADC_GetValue(&hadc1);   // канал 2 (PA2)
    HAL_ADC_Stop(&hadc1);
}
```

## Формат виводу
```
X:2048 (  +0%)  Y:2051 (  +0%)  CENTER      BTN:released
X:3900 ( +90%)  Y:2040 (  -0%)  RIGHT       BTN:released
```
Тут X і Y це сирі значення АЦП, у дужках відхилення у відсотках, далі напрям і стан кнопки.
